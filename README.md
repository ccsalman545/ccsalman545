## `01` / About me

I am **Muhammed Salman CC**, an M.Sc. Electronics student at the **Cochin University of Science and Technology (CUSAT)**, based in Kerala, India. I enjoy moving an idea from circuit architecture to dependable firmware, then connecting it to software that makes the system genuinely useful.

My current orbit is **embedded systems, Embedded Linux, robotics, FPGA design, AI/vision, IoT, and open source**. I am working toward a career in intelligent hardware: systems where careful electronics, maintainable code, and practical automation meet.

- **Build mode:** sensors, boards, scripts, and learning resources that can be reused.
- **Engineering lens:** measure first, read the datasheet, simplify the interface, document the result.
- **Open-source intent:** share work early, make it understandable, and improve it with feedback.

## `10` / Development philosophy

1. **Start with the constraints.** Read the datasheet, define interfaces, and know what “working” means.
2. **Prototype small.** Verify one sensor, driver, or module before joining the whole system.
3. **Measure; do not guess.** Logs, test points, and repeatable observations beat assumptions.
4. **Make failure visible.** Useful error messages and safe defaults are features.
5. **Prefer boring, maintainable solutions.** The best design is often the clearest one to debug next month.
6. **Document while building.** A project is not complete if someone else cannot reproduce the useful parts.
7. **Respect the hardware.** Electrical limits, calibration, and safety are part of software quality.
8. **Learn in public with humility.** Share progress, credit sources, and welcome better approaches.
